# ArduPilot & Ground Control Station Setup Guide

This guide details how to configure **ArduPilot** (Copter, Plane, Rover) and your Ground Control Station (**QGroundControl** or **Mission Planner**) for use with the **Dual-LRS** 915 MHz LoRa telemetry system.

---

## 1. ArduPilot Serial Port Configuration

Connect your flight controller to your GCS via USB, navigate to **Full Parameter List**, and set the parameters for the serial port connected to the Dual-LRS Air Unit (e.g. `TELEM1` / `SERIAL1` or `TELEM2` / `SERIAL2`):

| Parameter | Value | Description |
| :--- | :--- | :--- |
| **SERIAL1_PROTOCOL** | `2` | MAVLink2 (Enables full MAVLink v2 support) |
| **SERIAL1_BAUD** | `115` | 115200 baud (Default baud rate) |
| **BRD_SER1_RTSCTS** | `0` | Disabled (Hardware flow control not required) |

> [!NOTE]
> **Built-in Auto-Baud Detection:** Dual-LRS includes an automatic baud rate scanner. If ArduPilot's port is set to `57600`, `115200`, or `230400`, the Air unit automatically detects and locks onto the active baud rate when valid Heartbeats arrive.

### Recommended Telemetry Stream Rates (Hz)

To optimize bandwidth over the half-duplex LoRa link, configure the stream rate parameters (replace `SR1_` with `SR2_` if using TELEM2):

| Parameter | Value | Description |
| :--- | :---: | :--- |
| **SR1_POSITION** | `3` to `5` | GPS coordinates, groundspeed, altitude (3–5 Hz) |
| **SR1_EXTRA1** | `5` to `10` | Attitude (Roll, Pitch, Yaw) for HUD horizon (5–10 Hz) |
| **SR1_EXTRA2** | `3` to `5` | VFR HUD (Heading, throttle, climb rate) (3–5 Hz) |
| **SR1_EXTRA3** | `2` | Battery voltage, current, power sensors (2 Hz) |
| **SR1_RAW_SENS** | `1` | Raw IMU sensors (1 Hz) |
| **SR1_RC_CHAN** | `2` | RC channel inputs (2 Hz) |

## 2. Ground Station Connection

Dual-LRS supports both **QGroundControl (QGC)** and **Mission Planner**.

### Option A: QGroundControl (Recommended)

1. Connect the **Ground Unit** (ESP32-WROOM-32 or BlackPill) to your computer via USB.
2. In Linux, it enumerates as `/dev/ttyUSB0` (ESP32) or `/dev/ttyACM0` (BlackPill). In Windows, it appears as `COMx`.
3. Open QGroundControl:
   * Go to **Application Settings -> Comm Links**.
   * Click **Add**.
   * Name: `Dual-LRS`
   * Type: `Serial`
   * Port: Select your COM port or `/dev/ttyUSB0`
   * Baud Rate: `115200`
   * Click **Connect**.
4. QGroundControl will automatically request and download the full parameter table (1037 parameters complete in ~61 seconds) and display live telemetry on the HUD.
5. Signal strength bars and packet loss percentage reflect real-time link quality from the injected `RADIO_STATUS` packets.

### Option B: Mission Planner

1. Connect the **Ground Unit** via USB.
2. In the top-right corner of Mission Planner:
   * Select the corresponding `COMx` port.
   * Set baud rate to `115200`.
   * Click **Connect**.
3. Mission Planner will download parameters and open live telemetry streaming.

## 3. Link Quality & RSSI Visualization

Both QGroundControl and Mission Planner natively display telemetry link quality via standard MAVLink `RADIO_STATUS` (Message ID 109) generated by Dual-LRS:
* **RSSI / Signal Bars:** Displays current packet delivery success rate.
* **RemRSSI:** Shows remote radio status.
* **RxErrors / Dropped:** Displays rolling dropped packet count based on missing frame sequence numbers.
